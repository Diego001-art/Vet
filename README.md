# Сайт «Мягкий Свет»

Статический адаптивный сайт выездной ветеринарной службы: гуманное усыпление на дому, кремация, вывоз тела, урны.
Опубликован на GitHub Pages: https://diego001-art.github.io/Vet/

Ничего не выдумано: где нет реальных данных, на сайте стоит метка `[ADD REAL …]`, а в разметку Schema.org такие поля не попадают. Данных стороннего референсного сайта в файлах нет.

## Структура

```
_src/site.json        ← ВСЕ данные компании: название, телефон, мессенджеры, город, часы,
                         адрес, реквизиты, цены, зоны, районы, аналитика, ссылки на отзывы
_src/pages/*.html     ← тексты страниц (первая строка — заголовок, описание, Schema)
_src/build.py         ← сборщик: подставляет данные в HTML, Schema, sitemap, llms.txt
_src/icons.py         ← иконки и эмблема
site/                 ← готовый сайт (его публикует GitHub Pages из ветки gh-pages)
docs/                 ← рекомендации: Google, Яндекс, AI-поиск, площадки, отзывы, аналитика, отчёт
```

Страницы: главная, усыпление (общая, кошки, собаки), кремация, вывоз тела, цены + калькулятор, о службе, зона выезда, полезное + 4 статьи, вопросы и ответы, отзывы, контакты, политика конфиденциальности, 404.

## Как вписать свои данные

1. Откройте `_src/site.json` и заполните пустые поля (`""`, `null`, `[]`):

| Поле | Пример | Где появится |
|---|---|---|
| `city`, `cityIn` | `Казань`, `в Казани` | шапка, заголовки страниц, Schema `areaServed` |
| `serviceArea` | `Казань и пригороды до 30 км` | шапка, зона выезда, FAQ |
| `districts.city`, `districts.suburbs` | `["Вахитовский", …]` | страница «Зона выезда» |
| `phone` | `+7 (843) 123-45-67` | шапка, кнопка «Позвонить», подвал, Schema |
| `whatsapp` | `79001234567` (только цифры) | кнопки WhatsApp (плавающая, мобильная, в контактах) |
| `telegram` | `myvet` (без @) | кнопки Telegram |
| `email`, `hours` | | контакты, подвал, Schema |
| `openingHoursSchema` | `["Mo-Su 09:00-21:00"]` | Schema `openingHours` |
| `address`, `mapUrl` | | контакты, Schema |
| `legal` | ИП/ООО, ИНН, ОГРН, лицензия | подвал, «О службе», политика |
| `experience`, `visitDuration` | | «О службе», FAQ |
| `services.*.prices`, `extras.*.price`, `zones.*.price` | числа в рублях | таблицы цен, калькулятор, Schema `offers` |
| `reviewLinks` | ссылки на карточки в Яндексе / Google / 2ГИС | кнопки «Оставить отзыв» |
| `analytics`, `verification` | ID Метрики / GA4 / Clarity, коды Вебмастера / Search Console | счётчики (после согласия на cookie), мета-теги |
| `formEndpoint` | URL обработчика заявок | отправка форм (пока — демо-режим) |
| `siteUrl` | ваш домен, если подключите | canonical, sitemap, Schema |

2. Соберите сайт:

```bash
python3 _src/build.py
```

3. Опубликуйте: закоммитьте изменения и обновите ветку `gh-pages` из папки `site`:

```bash
git add -A && git commit -m "Обновил данные" && git subtree split --prefix site -b gh-pages-new && git branch -f gh-pages gh-pages-new && git branch -D gh-pages-new && git push origin main gh-pages
```

Вручную (не через `site.json`) заменяются: карточки врачей (`team_cards` в `_src/build.py`), отзывы (`review_cards`), фото урн и описания на `_src/pages/kremaciya.html`, пункты политики в `_src/pages/privacy.html`.

## Что проверить перед запуском

- Тексты о медицинской части (седация, показания) и о захоронении животных согласуйте с врачами.
- Политику конфиденциальности согласуйте с юристом.
- Подключите обработчик форм (`formEndpoint`), иначе заявки никуда не уходят.
