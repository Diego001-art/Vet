# Сайт «Мягкий Свет»

Статический адаптивный сайт выездной ветеринарной службы: усыпление на дому, кремация, вывоз тела, урны.
Структура и общее визуальное направление вдохновлены референсом, но реализация, тексты, эмблема, цвета и иллюстрации — свои.
Никаких данных оригинального сайта (название, адреса, телефоны, e-mail, имена, ИНН, карты, геометки, отзывы, фото, метрика) в файлах нет — это проверено поиском по всем файлам.

## Что внутри

```
site/                      ← готовый сайт, его и загружайте на хостинг
  index.html               Главная
  usyplenie.html           Усыпление на дому (виды питомцев, подготовка, цены)
  kremaciya.html           Кремация (форматы, сравнение, вывоз, урны, фотоотчёт)
  ceny.html                Цены + калькулятор
  o-nas.html               О службе, принципы, врачи, сведения о компании
  zona.html                Зона выезда
  stati.html               Полезное (фильтр по темам) + 4 статьи stati-*.html
  faq.html                 Вопросы и ответы
  otzyvy.html              Отзывы и форма обратной связи
  kontakty.html            Контакты
  privacy.html             Шаблон политики конфиденциальности
  404.html                 Страница «не найдено»
  robots.txt, sitemap.xml
  assets/js/config.js      ← ВСЕ ваши данные и цены — здесь
  assets/js/main.js        Интерактив: меню, калькулятор, формы, поиск, слайдер
  assets/css/style.css     Стили и цвета бренда (переменные в начале файла)
  assets/img/              Эмблема, фавиконки, картинка для соцсетей
_src/                      Исходники страниц и сборщик (нужны только для правок вёрстки)
```

## Как подставить свои данные — один файл

Откройте `site/assets/js/config.js` в любом текстовом редакторе и замените заглушки:

| Поле | Сейчас (заглушка) | Что указать |
|---|---|---|
| `phone` / `phoneHref` | +7 (000) 000-00-00 | Ваш телефон (для ссылки — только цифры с +) |
| `email` | info@example.com | Ваша почта |
| `hours` | Часы работы уточняются | Например, «Круглосуточно, без выходных» |
| `city`, `region` | Ваш город / и пригороды | Ваш город и область |
| `address` | пусто → блок скрыт | Адрес офиса или крематория |
| `messengers`, `socials` | пусто → кнопки скрыты | `{ label: "Telegram", url: "https://t.me/..." }` |
| `legal` | пусто → скрыто | ИП/ООО, ИНН, ОГРН для подвала и страницы «О службе» |
| `formEndpoint` | пусто → демо-режим | URL обработчика заявок (POST, JSON) |
| `demoPrices` | true | Поставьте `false`, когда впишете реальные цены |
| `services`, `extras`, `zones` | демо-цены | Ваши цены по весу, доплаты и зоны выезда |

Пустое значение `""` скрывает соответствующий блок на сайте.

**Ещё вручную (поиск по файлам):**
- Список районов на `zona.html` («Район 1…», «Населённый пункт 1…»).
- Карточки врачей («Имя Фамилия», «Фото врача») — в `_src/build.py`, функция `team_cards`, или прямо в HTML.
- Отзывы — только реальные, с согласия авторов. Сейчас стоят пометки «Место для отзыва».
- Фото: блоки с пометкой «Место для фото» — замените на свои изображения.
- `privacy.html` — заполните поля в [квадратных скобках] и согласуйте с юристом.
- Сайт опубликован на GitHub Pages: https://diego001-art.github.io/Vet/ . Если подключите свой домен — поменяйте адрес в `sitemap.xml`, `robots.txt` и `SITE_URL` в `_src/build.py`.

## Формы

Все формы проверяют телефон (маска +7) и согласие на обработку данных.
Пока `formEndpoint` пустой, заявка **никуда не отправляется** — посетитель видит пометку «Демо-режим».
Чтобы заявки приходили, укажите адрес своего обработчика (например, скрипт, который пересылает данные в Telegram или на почту). Отправляется JSON: `name, phone, topic, comment, consent, form, page`.

## Что проверить перед запуском

- Тексты про медицинскую часть (седация, показания) и про захоронение животных — согласуйте с вашими врачами.
- Реальные цены, зоны выезда и сроки.
- Если подключите систему веб-аналитики — добавьте уведомление о cookie и опишите это в политике.

## Как изменить вёрстку

Страницы собираются из `_src/pages/*.html` общим шаблоном (шапка, меню, подвал, формы):

```bash
python3 _src/build.py
```

Цвета бренда — переменные в начале `site/assets/css/style.css` (`--primary`, `--amber` и др.), там же тёмная тема.
