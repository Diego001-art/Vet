| Хранение персональных данных | Сайт сейчас их не собирает; приём заявок — только на сервер в РФ (docs/07) |

Ограничения хостинга: GitHub Pages не позволяет задавать свои заголовки сервера. Поэтому CSP задана через meta-тег, а X-Frame-Options (защита от встраивания сайта в чужие страницы) задать нельзя. При переезде на свой домен и хостинг эти заголовки нужно добавить на сервере.

Репозиторий публичный: в нём видны исходники, документация и дизайн-макеты. Персональных данных и секретов в нём нет. Если заказчик против — сделать репозиторий приватным (GitHub Pages для приватных репозиториев требует платный тариф GitHub Pro, $4 в месяц).
