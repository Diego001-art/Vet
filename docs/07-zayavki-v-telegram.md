# Заявки с сайта в Telegram

Заказчик выбрал: заявки приходят в Telegram. Сайт статический (GitHub Pages), поэтому токен бота нельзя хранить в коде страницы — его увидит любой посетитель. Заявки пересылает маленький бесплатный обработчик на Cloudflare Workers: `tools/telegram-worker.js`.

Пока обработчик не подключён, формы работают в демо-режиме: проверяют поля, но заявку никуда не отправляют.

## Что нужно от заказчика

1. Создать бота: в Telegram написать @BotFather → `/newbot` → придумать имя → получить **токен**.
2. Решить, куда приходят заявки: личный чат или группа (удобно, если отвечают несколько человек). Для группы — добавить в неё бота.
3. Написать боту (или в группу) любое сообщение и открыть в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найти `"chat":{"id": …}`. Это **CHAT_ID** (у групп начинается с минуса).

Токен — секрет: передавать только тому, кто подключает, не публиковать и не вставлять в файлы сайта.

## Подключение (10 минут)

1. Зарегистрироваться на dash.cloudflare.com (бесплатный тариф).
2. Workers & Pages → Create → Worker → вставить содержимое `tools/telegram-worker.js` → Deploy.
3. Settings → Variables and Secrets → добавить:
   - `BOT_TOKEN` (тип Secret) — токен бота;
   - `CHAT_ID` — id чата;
   - `ALLOWED_ORIGIN` — `https://diego001-art.github.io` (или будущий домен сайта).
4. Скопировать адрес воркера (`https://….workers.dev`) в `formEndpoint` в `_src/site.json`, запустить `python3 _src/build.py`, опубликовать.
5. Отправить тестовую заявку с сайта и проверить, что сообщение пришло.

## Что приходит в сообщении

Тема, имя, телефон, адрес или район, удобное время, расчёт из калькулятора (если был), страница, с которой отправлена заявка, отметка о согласии на обработку персональных данных.

## Важно по 152-ФЗ

Серверы Telegram и Cloudflare находятся за пределами России. Персональные данные россиян при сборе должны записываться в базу на территории РФ (ст. 18 ч. 5), а передача за рубеж требует отдельного уведомления Роскомнадзора. Перед запуском стоит обсудить с юристом заказчика; надёжный вариант — сохранять заявку в российском сервисе (CRM, почта на российском хостинге) и уже оттуда дублировать в Telegram. Текст политики конфиденциальности и согласия нужно будет дополнить сведениями о передаче данных.
