# Аналитика: Яндекс Метрика, Вебмастер, Search Console

Всё уже встроено в сайт. Счётчики **не загружаются**, пока вы не впишете их ID в `_src/site.json → analytics` и не пересоберёте сайт. Уведомление о cookie показывается при первом визите всегда; счётчики загружаются только после нажатия «Принять» (требование 152-ФЗ и хорошая практика).

## Что подключить

| Сервис | Зачем | Куда вписать |
|---|---|---|
| **Яндекс Метрика** | Главная аналитика для России, цели, Вебвизор | `analytics.metrika` — номер счётчика, например `12345678` |
| **Яндекс Вебмастер** | Индексация, региональность | `verification.yandex` — код из мета-тега |
| **Google Search Console** | Индексация в Google, запросы | `verification.google` — код из мета-тега |

После правки:

```bash
python3 _src/build.py
```

Затем опубликуйте сайт (см. README).

## События (уже настроены)

| Событие | Когда срабатывает | Параметры |
|---|---|---|
| `phone_click` | клик по любой ссылке `tel:` | `link_url` |
| `whatsapp_click` | клик по ссылке WhatsApp | `link_url` |
| `telegram_click` | клик по ссылке Telegram | `link_url` |
| `form_submit` | успешная отправка любой формы | `form`, `topic` |
| `booking_request` | заявка на услугу (усыпление, вывоз, кремация, «Узнать цену») или заявка с расчётом из калькулятора | `topic`, `has_calc` |
| `service_page_view` | открытие страницы услуги | `service` |
| `calculator_complete` | пользователь дошёл до итогового шага калькулятора | `situation`, `species` |

Все события попадают в `window.dataLayer` и в Яндекс Метрику (`reachGoal`).

Google Analytics и Microsoft Clarity с сайта убраны: они хранят данные за рубежом, а это запрещено при сборе персональных данных россиян (ч. 5 ст. 18 152-ФЗ) и требует уведомления о трансграничной передаче (ст. 12). Остаётся только Яндекс Метрика.

## Конверсии

**Яндекс Метрика → Цели** (тип «JavaScript-событие»), идентификаторы совпадают с названиями событий:

- `booking_request` — основная цель (заявка на услугу);
- `phone_click`, `whatsapp_click`, `telegram_click` — контакт;
- `form_submit` — любая заявка.


## Важно про формы

Пока `formEndpoint` в `site.json` пустой, формы работают в демо-режиме: проверяют поля, отправляют событие, но **заявку никуда не передают**. Перед запуском подключите обработчик, например простой серверный скрипт или сервис форм, который пересылает заявку в Telegram или на почту. Сайт отправляет JSON:

```json
{ "name": "", "phone": "+7 (...)", "topic": "Усыпление на дому", "time": "Сегодня", "location": "", "details": "расчёт из калькулятора", "consent": "yes", "form": "modal", "page": "/Vet/" }
```

## Проверка

1. Откройте сайт в режиме инкогнито, нажмите «Принять» в уведомлении о cookie.
2. В Метрике откройте отчёт «Посещаемость» в реальном времени.
3. Нажмите на телефон, отправьте тестовую заявку и проверьте, что события пришли.
